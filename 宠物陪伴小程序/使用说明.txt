宠物陪伴 · 微信小程序 —— 使用说明（纯文本版）
====================================================

一款简洁、干净、明了的线上宠物陪伴小程序：上传照片创建宠物档案，
在"另一个世界"与它互动、以宠物口吻聊天，并在社区分享日常。

- 无需注册即可体验：进入即用，一键领养默认宠物
- 隐私友好：照片默认隐私模式，最迟 24 小时自动删除
- 零依赖、可直接导入：微信原生小程序 + 云开发，
  未配置环境时自动进入演示模式


一、快速开始（演示模式，5 分钟）
----------------------------------------------------
演示模式不需要任何 AppID、云环境或密钥，所有数据保存在本机，
用于体验完整业务闭环。

1. 打开"微信开发者工具"，选择「导入项目」
2. 项目目录选择本文件夹（包含 project.config.json 的目录）
3. AppID 选择「测试号」（项目已内置 touristappid，会自动使用游客模式）
4. 点击「导入」即可运行
5. 首页点「免费体验（一键领养）」创建默认宠物，
   或走完整的三步创建流程

注意：页面中的「演示模式」横幅、聊天页的「演示回复」标签均为明确标识
——演示模式的回复来自本地模板，不是真实 AI 生成，也不会假装有长期记忆。


二、切换为真实云服务
----------------------------------------------------
需要：已注册的微信小程序 AppID（注册地址 https://mp.weixin.qq.com/ ）。

1. 填 AppID：打开 project.config.json，
   把 "appid": "touristappid" 改为你的 AppID
2. 开通云开发：开发者工具顶部点「云开发」→ 开通
   （选择按量付费，有免费额度）
3. 填环境 ID：打开 miniprogram/utils/config.js，
   把 cloudEnvId 填为你的环境 ID
   （云开发控制台 → 设置 → 当前环境 ID）
4. 创建数据库集合：在云开发控制台 → 数据库，
   创建下方第四节列出的 9 个集合，并按说明设置权限和索引
5. 部署云函数：在开发者工具中，右键 cloudfunctions 下每个函数文件夹
   →「上传并部署：云端安装依赖」，共 7 个：
   login / pet / chat / community / letter / cleanup / account
   （account 负责：立即删照片 / 清空全部数据 / 导出我的数据）
6. 部署定时清理：右键 cloudfunctions/cleanup →「上传触发器」
   （每小时自动执行一次清理）
7. 重新编译小程序，横幅消失即为真实模式

演示模式 / 真实服务切换方法总结：
- 演示模式：config.js 中 cloudEnvId 为空 → 数据在本机 Storage，
  聊天为本地模板回复（标注"演示回复"）
- 云端-演示回复：已配置环境，但未配模型密钥 → 数据在云数据库，
  云函数模板回复（响应中 isDemo: true）
- 云端-真实模型：已配置环境 + 模型密钥 → 数据在云数据库，
  真实大模型回复（isDemo: false）


三、接入真实大模型
----------------------------------------------------
模型调用统一封装在 cloudfunctions/chat/index.js 的适配层，
走 OpenAI 兼容接口（可替换 Provider）。

1. 在云开发控制台 → 云函数 → chat → 配置 → 环境变量，添加：

   MODEL_PROVIDER = openai-compatible
   MODEL_BASE_URL = https://你的服务地址/v1
   MODEL_NAME     = 你的模型名
   MODEL_API_KEY  = 你的密钥

2. 重新部署 chat 函数即可。
   密钥只存在服务端环境变量中，不进入小程序代码和仓库。
3. 更换 Provider：只需修改 chat/index.js 中的 generateReply，
   其余代码不变。
4. letter（一封信）云函数要单独再配一遍同样的四个变量：
   云函数各自独立部署，读不到 chat 的环境变量。
   没配时「一封信」会降级成按真实互动数据拼出的模板信，功能仍可用。


四、数据库集合与权限配置
----------------------------------------------------
在云开发控制台创建以下集合
（权限统一设为「仅创建者可读写」，社区读权限由云函数代读，
客户端不直连数据库）：

集合 users：
  字段 _openid, nickname, createdAt —— 用户身份

集合 pets：
  字段 _openid, name, personality(loyal/lively/foodie/friendly),
  type(cat/dog/other), ownerName, sinceDate,
  storageMode(private/persistent), photo(fileID), assetId, createdAt
  —— 宠物档案，一人一宠

集合 messages：
  字段 _openid, petId, role(user/pet), content, isDemo,
  createdAt, expiresAt —— 聊天记录

集合 posts：
  字段 _openid, ownerName, content, images[],
  likeCount, commentCount, createdAt —— 社区动态

集合 comments：
  字段 _openid, postId, ownerName, content, createdAt —— 评论

集合 likes：
  字段 _openid, postId, createdAt —— 点赞关系

集合 mediaAssets：
  字段 _openid, fileID, purpose(pet/post), storageMode, expiresAt,
  status(active/cleaned/failed/replaced), retryCount
  —— 素材生命周期管理

集合 reports：
  字段 _openid, postId, reason, status(pending), createdAt
  —— 举报记录

集合 letters：
  字段 _openid, petId, petName, ownerTitle, content, isDemo,
  stats, chatCount, createdAt
  —— 「一封信」AI 总结结果，每人只留最近 20 封

建议索引：
- posts.createdAt（倒序，分页查询）
- likes：postId + _openid 组合唯一索引（防重复点赞）
- mediaAssets.expiresAt、messages.createdAt（清理任务查询）

安全设计：所有写操作经云函数执行，服务端统一从
cloud.getWXContext() 获取身份，不信任客户端传入的用户 ID；
私有档案与聊天仅本人可读写；删除动态时同步清理评论、
点赞与存储文件。

六、数据保留规则（重要）
----------------------------------------------------
四条规则互相独立、互不混淆：

1. 隐私模式（默认）：宠物照片及衍生素材最迟上传（或切回隐私模式）
   后 24 小时内删除。实现：有效期设 22 小时 + 每小时清理任务
   （含重试缓冲，保证实际保留 < 24h，不会接近 48h）。
   过期后使用通用形象，可重新上传，也可在「我的」里立即删除。
2. 长期保存模式（主动选择）：宠物照片与形象持续保存、
   仅用于陪伴空间展示；可随时切回隐私模式并发起删除。
3. 换照片：旧素材标记为 replaced 并进入清理队列，
   隐私模式下随下一轮清理删除，不会留下旧文件。
4. 社区公开素材：属于用户主动发布行为，存储路径与宠物素材隔离
   （post/ 与 pet/ 前缀），不参与定时清理，
   仅随动态删除一并清理。

另外：聊天记录保留 90 天；信只保留最近 20 封（每 12 小时最多一封）。

两种删除的边界（别混）：
- 删除宠物及全部数据：删档案/照片/聊天/信/本机统计，社区动态保留
- 清空全部数据：上述全部 + 动态/图片/评论/点赞/举报，全部清空

查阅与导出：「我的 → 数据管理 → 查看并导出我的数据」，可整份复制。
专项测试：docs/隐私与数据管理专项测试.md；自动化 node tests/privacy.test.js


七、功能清单
----------------------------------------------------
已实现（第一版全部核心）：
- 免费体验 + 简短新手引导（无需注册，静默身份建立数据归属）
- 三步创建宠物：照片（本地预览/重选）→ 名字+性格
  （可选项可跳过）→ 保存模式确认
- 性格自定义：4 个底色 + 最多 3 个补充特质 + 口头禅/
  说话方式/小怪癖 + 4 个场景反应（摸摸/喂食/玩耍/被拎起），
  同时影响对话语气、互动飘字、提溜反应和一封信的口吻
- 陪伴页：轻量场景、待机/点击动效（纯 WXSS）、
  摸摸/喂食/玩耍/点击互动短句
- 宠物口吻对话：快捷话题、等待/失败/重发、防重复提交、
  频率限制、上下文按条数与字数双限裁剪；回复逐字输出；
  语音输入（按住说话转文字直发）与语音播报（自动/长按重听），
  插件未启用时自动降级为纯文字
- 社区闭环：发布（文字/图片）、游标分页、下拉刷新、图片预览、
  点赞/取消、评论/删除评论、删除动态（含关联数据清理）、
  举报（保存待处理记录）
- 宠物资料管理、隐私/长期保存模式切换、删除宠物及关联数据
- 加载中 / 空状态 / 失败 / 重试等完整状态
- 数据保留规则说明页内展示

九、费用提示
----------------------------------------------------
- 微信云开发：基础套餐有免费额度；超出后按量计费
  （数据库读写、云函数调用、存储与流量）
- 大模型 API：chat 函数配置的模型服务，按 Token 计费，
  费率取决于所选 Provider
- 短信/内容安全等：本项目未使用，无相关费用


十、开发假设记录
----------------------------------------------------
- 使用 JS 而非 TS：免去 npm/构建配置，保证"导入即运行"；
  类型约束通过 JSDoc 注释与运行时校验弥补
- 一人一宠：第一版简化，重复创建会替换旧档案
- 照片裁剪简化为"压缩 + 预览 + 重选"：避免引入裁剪依赖
- tabBar 使用纯文字：避免提交二进制图标资源
- 演示模式数据存本机 Storage，删除小程序即清空
- 时间格式化为相对时间（刚刚 / n 分钟前 / n 天前）
