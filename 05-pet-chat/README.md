# 05 宠物口吻对话

练：**模板化对话 + 情绪状态机**，纯本地、零成本、可上线。

## 跑起来

导入本目录，测试号即可。直接聊，或点快捷短语。

## 10 分钟讲解

| 文件 | 看什么 |
|---|---|
| `utils/replies.js` 的 `POOLS` | 按情绪分组的文案池。**文案质量 > 技术实现**，这块决定产品好不好用 |
| `RULES` + `detectMood` | 关键词命中情绪，顺序有意义（越具体越靠前） |
| `pick(list, last)` | 排除上一句，避免连着重复 —— 人设的可信度全靠这个 |
| `pages/index/index.js` 的 `send()` | 500~1200ms 随机延迟，模拟「在打字」，没有延迟会显得很假 |
| `scroll-into-view` | 定位到最后一条消息，比算 `scroll-top` 可靠 |
| `adjust-position` + `cursor-spacing` | 键盘不遮输入框的两个开关 |

## 为什么先不接大模型

1. 冷启动零延迟，体验反而更好
2. 文案可控，不会说出审核不允许的话
3. 接口以后随时能加：把 `reply()` 换成 `wx.cloud.callFunction({ name: 'chat' })` 即可，**页面代码一行不用动**

## 自测

- 输入「我回来了」「你饿不饿」「晚安」，看回的是不是不同情绪。
- 把 `POOLS.happy` 只留一条，再聊十句，观察 `pick` 如何避免重复。
- 给「睡觉」加一条规则，让它 22 点后自动说晚安（提示：`new Date().getHours()`）。
